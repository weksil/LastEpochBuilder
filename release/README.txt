Last Epoch Builder 0.1.1 for Windows x64
========================================

A Path of Building style planner for Last Epoch (game version 1.5.0, Season 5): exact numbers with a breakdown
of every value, items, idols, blessings, skill and passive trees, player and enemy conditions, import from
Last Epoch Tools links.

Run LastEpochBuilder.exe. No installation is needed. The interface language (English or Russian) is chosen in the
top bar. Settings are stored in %APPDATA%\Godot\app_userdata\LastEpochBuilder\settings.cfg.

Source code, documentation and the formula sources: https://github.com/weksil/LastEpochBuilder
